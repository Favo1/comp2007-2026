# comp2007-2026
TreasureQuest, a First-Person game made in Unity
https://github.com/Favo1/comp2007-2026

Treasure Quest is a first-person exploration game set inside a procedurally generated maze that's different every time you play.

Navigate winding stone corridors lit by torches and wall lamps, hunting down 5 hidden treasure chests scattered across the labyrinth. The final chest always waits at the far end of the maze — but getting there is the challenge.

Features

Procedurally generated maze — no two runs are the same
First-person exploration with a toggleable follow camera (press V)
Collect all 5 chests to win — each one plays an opening animation as you approach
Pause at any time (press Escape) and quit back to the main menu
Atmospheric low-poly art style with a night sky environment
How to Play

WASD — Move
Shift - Sprint
Mouse — Look around
V — Switch between first-person and follow camera
Escape — Pause / Resume
Walk up to a chest to collect it
Can you find all 5 treasures and escape the maze?

The 'Treasure Quest.exe' file lives inside the Build Folder
When running the .exe, ensure that you do so directly in the 'Build' folder so the execuable has all dependencies it needs to run.
